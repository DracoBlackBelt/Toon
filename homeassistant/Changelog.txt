2.1.0
 - Audit release. Fixed: main screen overlap - the alarm dialpad (right-aligned to its title, 170 px wide)
   sat on top of the switch column, and the dialpad ran off the bottom of the screen. The screen is now
   three anchored columns (scenes+slider | switches | alarm) whose sizes are derived from the real screen
   width and from the height that is left, so nothing overlaps or clips on any resolution.
 - Fixed: layout constants assumed isNxt = 800x480 and !isNxt = 400x240 (real Toon 1 is 800x480, so it got
   half-size widgets). All three screens now scale with the actual width instead.
 - Fixed: config screen second column and the SSL/clock toggles ran past the screen edge; port keyboard
   allowed only 4 digits (ports go to 65535); port is now validated 1-65535.
 - Fixed: sensor card overlapped the scene titles when few/no sensors were set; sensors are now listed
   compacted (no holes for empty slots) in two balanced columns, tile shows the first 3 configured sensors.
 - Fixed: sensor values - long decimals are rounded (21.3400001 -> 21.34), 'unavailable'/'unknown' shown as
   n.b./?, binary_sensor (open/dicht, beweging, aan/uit), climate (current temperature), weather, person.
   Value text no longer elided on the left ("...5 C") and no longer squeezes the name to nothing.
 - Fixed: 'connected' never dropped after Home Assistant went away (blank values forever); a cycle where every
   request fails or gets 401 now disconnects, so the 60 s timer retries. Poll counter could go negative after
   a watchdog timeout; stale callbacks no longer touch it.
 - Fixed: JSON request bodies are built with JSON.stringify (entity ids/codes with quotes broke them);
   token file tolerates quotes/newline/'Bearer ' prefix; server field accepts 'http://host:port/' input.
 - Added: status banner on the main screen (no token, token rejected, unreachable, entity not found with the
   offending entity id, failed command) - previously all of these were invisible unless debug was on.
 - Added: slider (input_number / number) back as - / + buttons using the entity's own min/max/step
   (setting 'Slider', configured on the Scenes page).
 - Added: scene slots also accept script/automation/button/input_button; switch slots also accept automation,
   cover, siren, humidifier, remote and group entities.
 - Added: alarm state shown as readable Dutch text (armed_away -> Aan (weg), triggered, pending...),
   disarm also while pending/arming/triggered, and panels without a code no longer require typing one.

2.0.0
 - Fork rewrite of the ToonSoftwareCollective app (own repo, own standards).
 - BREAKING: legacy api_password auth removed (dead since Home Assistant 2023.7); long-lived access token
   in /mnt/data/tsc/homeassistant.token.txt is now the only auth. The 'Pass'/'Legacy' settings and the
   separate sensors/scenes/sliders/switches/alarm side-files are gone; everything lives in
   homeassistant.userSettings.json (old files are NOT migrated - reconfigure once).
 - BREAKING: the 6-button "slider" (input_number hack) is removed from the UI.
 - All icons now load from the app's own drawables/ (relative paths) instead of qrc:/tsc paths that do
   not exist on current devices; button_on/off.png references (missing files) replaced by
   backgroundOn/Off.png.
 - Fixed: tile font/width operator-precedence bugs (5px clock text, 50px sensor labels on every device),
   inverted toggle-switch images for switches 2-5, switch3 mixed-up off-image, ReferenceError when
   typing a 5th alarm digit (bare "pass" in switch/default).
 - Fixed: try/catch used inside QML property bindings (invalid as expression) replaced by safe app-side
   helpers (sensorName/sensorValue/switchOn/...); no more binding errors or JSON.parse in UI files.
 - Fixed: settings only persisted as a side effect of checkConnection - "Opslaan" now saves first, then
   checks, and a stalled XHR can no longer lose input (watchdog Timer); config screen edits drafts and
   discards on back.
 - Fixed: unguarded homeAssistantScreen.* derefs at boot (crashed fetch callbacks before the screen
   existed), unguarded JSON.parse on failed/error responses, token file being overwritten with an empty
   file when unreadable.
 - Added: reconnect retry (60 s poll doubles as connection retry), poll generation guard, log message
   length cap, "Clock op tegel"/alarm features kept.
 - Layout: screens rebuilt with Repeater/Grid/Column + ToggleSwitch/ToggleBlock components and isNxt
   branches, so Toon 1 (400x240) is no longer clipped; all UI strings are qsTr() Dutch with lang/
   sources matching.
 - qmldir registers the screens explicitly (typed properties on the App).
